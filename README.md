# Happy
Happy is a Python based AI that is dedicated to helping people achieve personal growth through healthier living and be the best possible version of themselves. Happy gives evidence-proven advice in cognitive techniques, behavior techniques, and coping techniques. Happy remembers past conversations and learns who the user is over time. Happy is still in early development.
